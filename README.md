# HW 1: Language Models from Scratch (Part 1)

Character-level language models on Tiny Shakespeare, built with the course codebase
[`nanolm`](https://github.com/lkk688/DeepDataMiningLearning/blob/main/DeepDataMiningLearning/llm/TUTORIAL_nanolm.md)
(commit `8418fc1`, unmodified). The experiments compare RNN, GRU, LSTM and Transformer models under the same token
budget, measure how much context each one uses, and analyze what the Transformer's attention heads do.

**Report:** [`report/report.pdf`](report/report.pdf) (source: [`report/report.md`](report/report.md))

## Key results

| Task | Result |
|---|---|
| 1. Metrics by hand | Perplexity and bpb recomputed from `metrics.json` match the logged values exactly. Untrained loss = 4.197 vs ln 65 = 4.174 (char) and 10.823 vs ln 50257 = 10.825 (GPT-2 BPE). |
| 2. Architectures (16.4M tokens, 2 seeds) | Modern Transformer **2.116** bpb < LSTM 2.137 < GRU 2.160 < LSTM-512 2.170 < GPT-2-style Transformer 2.185 ≪ vanilla RNN 2.437. LSTM-512 is best at 8M tokens, then overfits. |
| 3. Context length 64–512 | With sliding-window evaluation, the LSTM gains nothing beyond 64 characters and the Transformer nothing beyond 128. Most of the apparent gain under standard evaluation is a cold-start artifact. |
| 4. Attention | Previous-token heads (up to 0.58 avg. weight vs 0.05 uniform), a word-start head (0.30–0.35), a speaker-line head (0.34). No induction heads. |
| Extra credit | A gate-by-gate GRU matches `nn.GRU` to 1e-15 (float64), including gradients and a 30-step training run. |

All numbers are mean of 2 seeds (1337, 42). Hardware: Apple M4 Pro, MPS, fp32. Total compute: about 75 minutes.

## How to reproduce

### Setup

```bash
mkdir work && cd work
git clone https://github.com/Anuragbo/nanolm.git nanolm      # this repository

# the course code (only the llm/ folder is needed)
git clone --depth 1 --filter=blob:none --sparse https://github.com/lkk688/DeepDataMiningLearning.git
git -C DeepDataMiningLearning sparse-checkout set DeepDataMiningLearning/llm

uv venv --python 3.12 .venv && source .venv/bin/activate   # or: python -m venv .venv
uv pip install torch numpy pyyaml sentencepiece tiktoken pandas matplotlib scipy huggingface_hub datasets pytest

cd DeepDataMiningLearning/DeepDataMiningLearning/llm       # every command below runs from here
HW=../../../nanolm                                         # path to this repository
cp $HW/configs/hw1_context.yaml nanolm/configs/sweeps/     # the sweep's `base:` path is relative to the sweeps folder

python -m pytest nanolm/tests -q                           # expect: 28 passed, 3 skipped
```

Each run writes `outputs/nanolm/<date>_<name>/` or `outputs/nanolm/sweeps/<sweep>/<run>_s<seed>/`, with
`config.yaml`, `meta.json`, `train_log.jsonl`, `eval_log.jsonl`, `metrics.json`, `sample.txt` and `model.pt`.

### Task 1: metrics by hand (about 2 min)

```bash
python -m nanolm.train -c nanolm/configs/laptop/L1_char_lstm.yaml name=hw1_t1_trained_char_lstm
for tok in char gpt2; do
  python -m nanolm.train -c nanolm/configs/laptop/L1_char_lstm.yaml name=hw1_t1_init_$tok  data.tokenizer=$tok train.max_steps=1 train.lr=0
  python -m nanolm.train -c nanolm/configs/laptop/L1_char_lstm.yaml name=hw1_t1_step1_$tok data.tokenizer=$tok train.max_steps=1
done
python -m nanolm.train -c nanolm/configs/laptop/L1_char_lstm.yaml name=hw1_t1_step1_nowarmup_char train.max_steps=1 train.warmup_steps=0
python $HW/scripts/task1_metrics.py --out $HW/results/task1_metrics.md
```

### Task 2: RNN vs GRU vs LSTM vs Transformer (about 35 min)

```bash
python -m nanolm.sweep --sweep nanolm/configs/sweeps/01_char_models.yaml
python -m nanolm.analyze outputs/nanolm/sweeps/char_models --baseline gpt_textbook --metric val_bpb
python $HW/scripts/task2_plots.py --sweep outputs/nanolm/sweeps/char_models --out $HW
```

### Task 3: context length (about 38 min)

```bash
python -m nanolm.sweep --sweep nanolm/configs/sweeps/hw1_context.yaml
python -m nanolm.analyze outputs/nanolm/sweeps/hw1_context --baseline gpt_ctx256 --metric val_bpb
for d in outputs/nanolm/sweeps/hw1_context/*_s*; do                # sliding-window re-evaluation, stride = seq_len/8
  T=$(echo $d | sed -E 's/.*ctx([0-9]+)_s.*/\1/')
  python -m nanolm.compress $d --bits --strides 0 $((T/8))
done
python $HW/scripts/task3_context.py --sweep outputs/nanolm/sweeps/hw1_context --out $HW
```

### Task 4: attention analysis (about 1 min, uses a Task 2 model)

```bash
RUN=outputs/nanolm/sweeps/char_models/gpt_modern_s1337
for kind in shakespeare modern_prose repeated; do
  case $kind in
    shakespeare)  TEXT=$'ROMEO:\nBut soft! what light through yonder window breaks?\nIt is the east, and Juliet is the sun.' ;;
    modern_prose) TEXT="The researchers trained a small model on a laptop, and it learned to spell words before grammar." ;;
    repeated)     TEXT="the quick brown fox jumps over the lazy dog. the quick brown fox jumps over the lazy dog." ;;
  esac
  python -m nanolm.viz attention --run $RUN --text "$TEXT"
  cp docs/nanolm_figs/p1_attention_maps.png $HW/figures/task4_attn_$kind.png
done
git -C ../.. checkout -- DeepDataMiningLearning/llm/docs/nanolm_figs/p1_attention_maps.png   # restore the course figure
python $HW/scripts/task4_heads.py --run $RUN --out $HW
```
